# Metisova — State-of-the-art company website

A responsive, single-page, high-end company website for Metisova. It is deliberately inspired by the visual discipline of premium technology companies (large typography, black/white contrast, restrained accent color, cinematic motion), without copying any proprietary site.

## Included
- Responsive landing page
- Interactive hero/parallax effects
- Animated Atlas live-world visual
- Interactive division list
- Product portfolio cards
- Metisova Labs invention pipeline
- Contact CTA
- Mobile layout

## Metisova structure used
The website intentionally excludes **Metisova Quantum**, per the current company direction.

Divisions represented: Metisova AI, Metisova Medical, Metisova Biosciences, Metisova Robotics, Metisova Education, Metisova Labs, Metisova Ventures.

Products represented: Atlas, Real-Time Universal Translator, Nigerian Multilingual AI, AI Language Tutor, Ultra-Low-Cost Genome Sequencing, AI-Enhanced MRI.

## Deploy
Upload `index.html`, `styles.css`, and `script.js` to the hosting provider connected to your metisova.com domain.

For a production launch, replace the abstract generated visuals with licensed high-resolution photography/renderings and connect the contact form/email infrastructure.
